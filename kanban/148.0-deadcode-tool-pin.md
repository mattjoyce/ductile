# Card 148 slice 0: drop the `tool` directive for deadcode

## Problem now

`golang.org/x/tools`, `golang.org/x/mod`, `golang.org/x/sync` and `golang.org/x/telemetry`
into the module graph (`go.mod` require block and `go.sum`). None of them is in the binary.
