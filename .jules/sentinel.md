## 2026-06-28 - [Subprocess launched with variable]
**Vulnerability:** gosec G204 reported a Subprocess launched with variable in `internal/dispatch/sidedoor_audit_unix.go` (CWE-78: Improper Neutralization of Special Elements used in an OS Command).
**Learning:** In Go, when passing a variable to `exec.CommandContext` (like the username in `exec.CommandContext(ctx, sudo, "-n", "-l", "-U", username)`), gosec triggers a G204 warning due to potential command injection. However, because the executable (`sudo`) is explicitly resolved, and the arguments are passed as separate strings to the variadic `exec.CommandContext` function rather than being concatenated into a single shell string, the `os/exec` package handles the argument separation safely. The user input cannot inject arbitrary commands or options.
**Prevention:** When arguments are strictly and safely separated in `exec.Command` or `exec.CommandContext`, and the inputs are trusted, suppress the G204 false positive by adding a `// #nosec G204` comment above the command creation, accompanied by an explicit explanation of why the input is safe (e.g. `// #nosec G204 -- The arguments are safely separated...`) to maintain clear security intent documentation.
