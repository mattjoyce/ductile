## 2025-02-24 - [CRITICAL] Fix SQL injection in sqliteColumnExists
**Vulnerability:** The function `sqliteColumnExists` in `internal/storage/sqlite.go` used string formatting (`fmt.Sprintf("PRAGMA table_info(%s);", table)`) to construct a PRAGMA statement, which is vulnerable to SQL injection if `table` was user-controlled.
**Learning:** SQLite's standard PRAGMA statements cannot use parameterized arguments for the pragma value itself. However, many pragmas have table-valued function equivalents (e.g., `pragma_table_info(?)`) that DO support parameterization.
**Prevention:** Always use table-valued function equivalents of PRAGMA statements (like `pragma_table_info`, `pragma_index_list`, etc.) when you need to provide dynamic parameters instead of string concatenation/interpolation. Note that when explicitly selecting columns from `pragma_table_info(?)`, the `notnull` column must be enclosed in double quotes (e.g., `"notnull"`) as it is a reserved keyword in SQL syntax.
