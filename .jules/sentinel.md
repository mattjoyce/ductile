## 2026-06-11 - [CRITICAL] Fix SQL Injection in sqliteColumnExists
**Vulnerability:** The function `sqliteColumnExists` in `internal/storage/sqlite.go` formatted a table name using `fmt.Sprintf("PRAGMA table_info(%s);", table)`. This allows for SQL injection if the table name is under attacker control, which is problematic since SQLite doesn't natively support parameterized pragmas with dynamic strings in all drivers.
**Learning:** SQLite's `PRAGMA` commands don't support bound parameters for identifiers (like table names). However, SQLite version 3.16.0+ introduced table-valued functions, like `pragma_table_info('table_name')`, which *can* accept bound parameters when used via a `SELECT` statement. Also, `notnull` is a reserved keyword in SQLite, requiring double quotes in the `SELECT` clause (`"notnull"`).
**Prevention:** Always use `SELECT ... FROM pragma_table_info(?)` instead of `PRAGMA table_info(...)` when retrieving schema details, to ensure parameterized inputs are used for table names.
